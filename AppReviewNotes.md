BOKKI Chart 1.0 — App Review Notes

The app has no account registration, login, account deletion, user-generated content, or paid content/In-App Purchases, so none of those flows exist.

2. PURPOSE AND TARGET AUDIENCE
BOKKI Chart shows reference color charts (X-Rite ColorChecker Classic and others, gray ramps, skin tone charts) full screen on an iPhone or iPad. Video makers and photographers point a camera at the screen to check or tune their camera's color (white balance, color science, LUT matching) without carrying a physical chart. It solves the cost and inconvenience of physical charts. Brightness is locked to 100% while a chart is open so the display output stays consistent.
It is a color reference tool only; it does not diagnose, measure skin, or give medical advice.

3. HOW TO USE THE MAIN FEATURES
No login, sample files, or setup are needed. Launch the app, tap any chart in the home list (e.g. "ColorChecker Classic"), and the chart opens full screen. Tap a patch to see its values (24/16/10/8 bit, Display P3 / sRGB) and to fine-tune it. The slate and skin tone charts are in the same list.
The display check screen can optionally run the user's own Apple Shortcuts shortcut (e.g. "BOKKI Shoot Mode") to switch iOS display settings that apps cannot change (True Tone, Night Shift, etc.). It is optional; the app works fully without it.
The "BOKKI CAM calibration link" is optional. It lets our separate camera app, BOKKI CAM, request charts over the local network. It requires a second device running BOKKI CAM and is not needed to review the app. The Local Network permission prompt appears only for this feature; declining it does not affect anything else.

4. EXTERNAL SERVICES / THIRD-PARTY COMPONENTS
None. The app works fully offline: no servers, accounts, analytics, advertising, payments, or AI services. All chart data is bundled in the app. Local-network (Bonjour) communication is used only for the optional BOKKI CAM link, between devices on the same network.
Chart values come from published data: X-Rite (2016) ColorChecker specifications, BabelColor averages, the Image Engineering TE226 V2 data sheet, colour-science datasets (BSD-3-Clause), the Monk Skin Tone Scale (Google, CC BY 4.0), and the ITA skin classes (Del Bino et al., 2006). Values labeled as BOKKI-defined are app-defined, not published standards.

5. REGIONAL DIFFERENCES
None. The app functions identically in all regions. The UI is in English and Korean, following the device language.
